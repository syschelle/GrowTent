# GrowTent v0.4.27

## Release summary

GrowTent v0.4.27 makes one more focused layout refinement to the compact Operating Settings page. On wide desktop screens, the Temperature card is reduced significantly again so the surrounding cards gain more usable width, especially the Irrigation Settings card. This keeps the four-card top row while using the available Full-HD width more efficiently.

## Highlights

- Reduces the Temperature card width again in the top Operating Settings row.
- Reassigns the freed width primarily to the Irrigation Settings card.
- Keeps the four-card Full-HD layout introduced in v0.4.26.
- Keeps the 2x2 fallback below desktop widths and single-column mobile layout.
- Preserves all existing field IDs, save handlers, and API behavior.
- Updates firmware and asset cache-buster metadata to v0.4.27.

## Compatibility

- No API changes.
- No control-logic changes.
- Layout-only refinement.

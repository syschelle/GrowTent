# GrowTent v0.4.24

## Release summary

GrowTent v0.4.24 refines the compact Operating Settings layout from v0.4.23. The top section now uses a four-column layout on wide screens so Grow periods, Temperature, VPD Settings, and Irrigation Settings sit on one horizontal row. In addition, the Grow periods card is simplified so all three date inputs are stacked vertically for faster scanning.

## Highlights

- Changes the top Operating Settings layout to a four-column row on wide desktop screens.
- Places Grow periods, Temperature, VPD Settings, and Irrigation Settings in one horizontal level when space allows.
- Changes the Grow periods card so Start Grow, Start Flowering, and Start Drying are shown vertically one below another.
- Keeps the restrained GrowTent color palette and all existing control IDs and save logic unchanged.
- Adds a responsive breakpoint so the four-column row falls back to two columns on medium screens and one column on mobile.
- Advances firmware and static-asset cache-buster metadata to v0.4.24.

## Compatibility

- No API contract changes.
- No automation or control-logic changes.
- Existing settings storage and save handlers remain unchanged.

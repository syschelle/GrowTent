# GrowTent v0.4.30

## Release summary

GrowTent v0.4.30 makes a small visual refinement to the compact Operating Settings page. The three cards in the first row now again share the same height so the row looks visually aligned and calmer, while the separate spacing to the Irrigation section below remains intact.

## Highlights

- Restores equal-height cards for the first Operating Settings row.
- Keeps Grow periods, Temperature, and VPD visually aligned on desktop layouts.
- Preserves the spacing between the first row and the lower Irrigation section.
- Keeps all form IDs, save handlers, and logic unchanged.
- Updates firmware and static asset metadata to v0.4.30.

## Compatibility

- No API changes.
- No automation or control-logic changes.
- Layout-only refinement.

# v0.5.8 — compact irrigation plan fields

## Changes

- Reduce the width of the interval, light-on offset and last-watering date inputs.
- Group the fields more compactly while retaining the responsive mobile layout.
- Rename the offset label to **Offset nach Licht-an (Minuten)** in German and **Offset after light-on (minutes)** in English.

## Compatibility

Display-only changes. Irrigation scheduling, history, persistence, HMAC and pump behavior remain unchanged from v0.5.7. Use the firmware intended for your board.

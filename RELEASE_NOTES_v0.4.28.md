# GrowTent v0.4.28

## Release summary

GrowTent v0.4.28 further refines the Operating Settings layout. Irrigation Settings, all irrigation parameters, and the optional Heating Relay configuration are now grouped into one horizontal operations row on wide desktop screens. This reduces vertical scrolling and keeps related operating controls together.

## Highlights

- Groups Irrigation Settings, Irrigation Parameters, and Heating Relay into one horizontal row on wide desktop screens.
- Displays the six irrigation parameters in a compact 3 x 2 grid.
- Keeps Pump/Flood controls in their own card within the same row.
- Keeps Heating Source and Heating Relay together in the third card.
- Uses responsive fallbacks: two columns on medium desktops and one column on smaller screens.
- Preserves all existing field IDs, save handlers, storage behavior, and API contracts.
- Advances firmware and static-asset cache-buster metadata to v0.4.28.

## Compatibility

- No API changes.
- No automation or control-logic changes.
- Layout-only refinement.
